# Number Base Converter & Logic Gates

A simple CLI tool for converting between number systems and viewing basic logic gate truth tables.

## Features
- Decimal ↔ Binary conversion
- Decimal ↔ Hexadecimal conversion
- Truth table for AND, OR, NOT gates

## How to Run
```bash
python3 converter.py
```

## Requirements
- Python 3.6+
- No external dependencies

Useful for revising digital electronics / computer organization basics.
